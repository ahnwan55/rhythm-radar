# 알파 점포 기종 검수표 템플릿

## 1. 목적

이 문서는 알파 대상 점포의 표시 기종과 분류별 기체 수를 관리자 검수로 확정하기 위한 작성 양식입니다. 현재는 점포 목록만 확정되어 있으며, 기종명과 기체 수는 증거 확인 전까지 비워 둡니다.

## 2. 작성 규칙

- 한 점포에 표시 대상 기종이 여러 개면 행을 추가합니다.
- 기체 수는 현장 사진, 점포 공지 또는 확인 가능한 제보 근거와 함께 기록합니다.
- 전체 기체 수, 추적 대상 기체 수, 가동 중 추적 대상 기체 수, 구버전 기체 수는 관리자 승인 전까지 공개 데이터로 사용하지 않습니다.
- 최신 온라인 업데이트가 유지되는 현역 기체만 추적 대상 및 가동 중 추적 대상 수에 포함합니다.
- 구버전, 업데이트 중단 또는 오프라인 기체는 대기열과 체감 혼잡도 계산에서 제외하며, 최신 기체와 혼재하면 비고에 참고 정보를 기록합니다.
- 사진에 얼굴이나 개인정보가 노출되었으면 공개 사용을 중단하고 처리 메모를 남깁니다.
- 기본 등록 기준을 충족하지 않는 점포는 예외 등록 검토 근거를 기록합니다.

## 4. 상태 값

| 값 | 의미 |
| --- | --- |
| `대기` | 근거 수집 전 |
| `검토 중` | 근거는 있으나 관리자가 결론을 내리지 않음 |
| `승인` | 공개 기준 데이터로 사용할 수 있음 |
| `보류` | 추가 근거가 필요하거나 등록 판단을 미룸 |
| `반려` | 알파 표시 대상으로 사용하지 않음 |

## 5. 검수 완료 조건

- 알파 대상 점포 6곳 모두에 검수 상태가 기록됩니다.
- `승인` 상태인 행에는 기종/모델, 등록 유형, 네 가지 기체 수, 검수 근거, 검수일이 채워집니다.
- 구버전 또는 업데이트 중단 기체가 혼재하는 승인 행은 해당 수와 계산 제외 사실이 비고에 기록됩니다.
- 동일 점포의 여러 기종을 표시할 경우 기종별로 각각 승인 여부가 기록됩니다.
- `보류` 또는 `반려`인 행에는 사유가 비고에 기록됩니다.
