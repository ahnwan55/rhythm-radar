# 점포 선정 및 등록 기준

## 1. 목적

리듬레이더는 모든 오락실 정보를 포괄하는 디렉터리가 아니라, 리듬게임 이용자가 방문 전 대기 상태를 확인할 필요가 큰 점포를 우선 다룹니다. 이 문서는 신규 점포의 기본 등록 기준과 예외 등록 원칙을 정의합니다.

## 2. 기본 등록 기준

점포는 다음 중 하나 이상을 현재 가동하고 있음을 확인할 수 있을 때 기본 등록 대상이 됩니다.

- 사운드 볼텍스 발키리 모델
- BEMANI 최신 온라인 리듬게임

여기서 `가동`은 신버전 온라인 업데이트가 유지되며 이용자가 플레이할 수 있는 상태로 운영 중인 버전을 의미합니다. 기체의 신구 여부 자체는 등록 기준이 아니며, 구버전, 업데이트 중단, 오프라인, 단순 보유 또는 장기간 고장 기체는 대기열 추적 대상이나 기본 등록의 가동 근거로 보지 않습니다.

## 3. 예외 등록 기준

BEMANI 기종을 취급하지 않는 점포라도 특정 리듬게임 전문점은 예외적으로 등록할 수 있습니다.

예외 등록 검토 시 다음을 종합적으로 확인합니다.

| 검토 항목 | 확인 내용 |
| --- | --- |
| 전문성 | 특정 리듬게임을 중심으로 여러 대의 기기를 운영하거나 이용자 방문 목적이 분명한가 |
| 수요 | 대기 상태 공유가 방문 판단에 실질적으로 유용할 정도의 이용 수요가 있는가 |
| 운영 지속성 | 단기 이벤트성 설치가 아니라 지속 운영 가능성이 있는가 |
| 검수 가능성 | 기종, 기체 모델, 소프트웨어/서비스 버전, 최신 온라인 추적 대상/가동 중 추적 대상 기체 수를 확인할 자료 또는 현장 제보가 있는가 |

예외 등록 여부는 관리자가 근거와 결정 사유를 기록한 후 승인합니다.

## 4. 등록 절차 초안

1. 후보 점포의 이름, 위치, 대상 기종 정보를 수집합니다.
2. 기본 기준 충족 여부 또는 예외 검토 필요 여부를 분류합니다.
3. 현장 사진, 점포 공지, 신뢰 가능한 제보 등으로 초기 기기 정보를 확인합니다.
4. 관리자가 점포와 기종별 전체 기체 수, 추적 대상 최신 온라인 기체 수, 현재 가동 중인 추적 대상 기체 수, 추적 제외 기체 수를 승인합니다.
5. 등록 완료 후 로그인 이용자의 대기 상태 제보를 허용합니다.

## 5. 등록 후 변경 관리

- 신규 기종 추가, 기기 철수, 장기 고장, 수리 완료는 증거 사진 제보 대상입니다.
- 변경 사항은 관리자가 승인한 시점부터 공개 정보에 반영합니다.
- 구버전, 업데이트 중단 또는 오프라인 기체는 참고 정보로 남길 수 있으나 대기열 및 체감 혼잡도 계산에서 제외합니다. 최신 온라인 추적 대상과 혼재하는 추적 제외 정보는 `machineGroups`와 `notes`에 기록합니다.
- 점포가 기본 기준을 더 이상 충족하지 않더라도 즉시 삭제하지 않고, 운영 상태와 이용 수요를 확인해 유지 또는 비공개 전환을 판단합니다.
- 점포명 변경이나 이전은 동일 점포의 이력 유지가 가능한지 검토해 처리합니다.

## 6. 알파테스트 지정 점포

알파 1차에서는 운영자가 직접 검수하고 반복 확인할 수 있는 서울·부천권 5개 점포를 초기 운영 대상으로 지정합니다. 이 목록은 알파 범위를 정하기 위한 선정 결과이며, 각 점포의 실제 표시 기종과 분류별 기체 수는 별도 검수 후 확정합니다.

| 점포 | 권역 | 초기 등록 상태 |
| --- | --- | --- |
| 노량진 어뮤즈타운 | 서울 | 알파 1차 대상, 현장 조사 완료 |
| 태릉입구역 비트연구소 T | 서울 | 알파 1차 대상, 현장 조사 완료 |
| 한성대 우리게임장2 | 서울 | 알파 1차 대상, 현장 조사 일부 완료 |
| 부천 어택 | 경기 | 알파 1차 대상, 현장 조사 완료 |
| 부천 P2존 | 경기 | 알파 1차 대상, 현장 조사 완료 |

### 알파 2차 예정

| 점포 | 권역 | 초기 등록 상태 |
| --- | --- | --- |
| 주안 CPU 게임랜드 | 인천 | 알파 2차 테스트 예정 |

주안 CPU 게임랜드는 인천권 주요 리듬게임 점포로 알파 2차 테스트 예정에 둡니다. 알파 1차에서는 서울·부천권 직접 검수 범위를 우선하므로, 운영자 직접 방문 전까지 공개 확정 데이터로 사용하지 않습니다.

## 7. 판단 기록 항목

신규 등록 또는 예외 등록을 처리할 때 관리자는 최소한 다음 정보를 기록합니다.

| 항목 | 설명 |
| --- | --- |
| 점포 식별 정보 | 점포명, 주소 또는 위치 설명 |
| 등록 유형 | 기본 등록 또는 예외 등록 |
| 대상 기종 | 대기 상태를 제공할 기종 목록 |
| 검수 근거 | 사진, 공지, 현장 확인 등 |
| 결정자와 결정 시각 | 승인 이력 확인용 |
| 비고 | 예외 승인 사유 또는 후속 확인 필요 사항 |

알파 지정 점포의 실제 검수 기록은 [alpha-store-inventory-template.md](alpha-store-inventory-template.md)를 복제하거나 갱신하여 작성합니다. 검수 전에는 기종명이나 기체 수를 추정값으로 공개하지 않습니다.
