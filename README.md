# 리듬레이더 (Rhythm Radar)

리듬레이더는 수도권 주요 리듬게임 오락실의 기종별 대기 상태를 이용자 제보로 공유하는 웹앱입니다.

현재 단계는 **알파테스트 기획 및 운영 정책 정리**입니다. 아직 애플리케이션 코드는 작성하지 않으며, 문서와 MVP 이슈를 기준으로 제품 범위와 의사결정 사항을 구체화합니다.

## 해결하려는 문제

리듬게임 이용자는 방문 전에 원하는 기종을 얼마나 기다려야 하는지 확인하기 어렵습니다. 리듬레이더는 정확한 대기 인원 집계 대신, 현장에서 빠르게 제보할 수 있는 **구간형 대기 상태**를 제공합니다.

## 핵심 원칙

- 대기 상태는 로그인한 이용자가 기종별로 제보합니다.
- 정확한 인원 수 대신 `없음`, `짧음`, `보통`, `김`, `확인 필요`와 같은 구간을 사용합니다.
- 총 기기 수와 가동 기기 수는 관리자 검수를 거쳐 관리합니다.
- 고장 기기 또는 기기 수 변경은 증거 사진 제보 후 관리자 승인을 거쳐 반영합니다.
- 체감 혼잡도는 검수된 가동 기기 수와 최신 대기 상태를 조합해 계산합니다.
- 알파 단계의 분탕 대응은 로그인, 제보 로그 저장, 제보 쿨타임을 기본으로 합니다.

## 알파테스트 점포

알파테스트는 다음 6개 점포를 대상으로 시작합니다.

| 점포 | 지역 |
| --- | --- |
| 노량진 어뮤즈타운 | 서울 노량진 |
| 태릉입구역 비트연구소 T | 서울 태릉입구 |
| 한성대 우리게임장2 | 서울 한성대 |
| 부천 어택 | 경기 부천 |
| 부천 P2존 | 경기 부천 |
| 주안 CPU 게임랜드 | 인천 주안 |

각 점포에서 실제로 표시할 기종과 기기 수는 알파 시작 전 관리자 검수 대상으로 둡니다.

## 등록 기준

기본 등록 대상은 다음 조건 중 하나를 만족하는 점포입니다.

- 사운드 볼텍스 발키리 모델을 가동하는 점포
- BEMANI 최신 온라인 리듬게임을 가동하는 점포

BEMANI를 취급하지 않더라도 특정 리듬게임에 특화되어 이용자 수요가 명확한 전문점은 예외 등록할 수 있습니다. 상세 기준은 [docs/store-selection-rules.md](docs/store-selection-rules.md)를 따릅니다.
